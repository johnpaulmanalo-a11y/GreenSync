Team Workflow and Branching

Home Git Setup Team Workflow

1. Create a Branch Before Working

git checkout main
git pull origin main
git checkout -b feature-your-page

Each member creates a separate branch for their assigned page so changes stay isolated until reviewed.

2. Commit and Push Changes

git add .
git commit -m "Add workflow page content"
git push -u origin feature-your-page

This saves the changes locally and uploads the branch to GitHub for the team to see.

3. Open a Pull Request

Open a Pull Request on GitHub:
feature-your-page -> main

A teammate reviews the changes before merging the branch into main.

4. Update Local Main Branch

git checkout main
git pull origin main

After merging, everyone pulls the updated main branch to stay in sync.

Important

Always pull the latest main before creating a new branch to avoid merge conflicts.
